# unitree-g1-physical-ai

Unitree G1を使ったフィジカルAIの実験・検証プロジェクト。

## 概要

Unitree G1（ヒューマノイドロボット）を対象に、身体性を持つAIエージェントとしての振る舞いを実験・検証していく。テーマは今後拡張予定で、現時点では以下の2つに取り組む。

- **voice-conversation** — G1上での音声会話（マイク入力・音声認識・対話・音声合成）の検証
- **gdl-integration** — Ghost Description Language (GDL) をG1のエージェント人格記述として組み込む実験

## ディレクトリ構成

テーマごとに1フォルダとし、そのテーマのドキュメントとソースコードを同じフォルダにまとめる。

```
.
├── README.md
├── .gitignore
├── voice-conversation/
│   ├── README.md      # 検討事項・実験ログ
│   └── (コード)
└── gdl-integration/
    ├── README.md      # 検討事項・実験ログ
    └── (コード)
```

新しいテーマを追加する際は、ルート直下に `<テーマ名>/` を作成し、その中に `README.md`（検討ノート）とコードを配置する。
